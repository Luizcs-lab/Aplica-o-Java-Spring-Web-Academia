# Gestor de Academia

## 🏗️ Objetivo:
- Sistema de gerenciamento e administração de academia, controle sobre quem frequenta o estabelecimento e os equipamentos que dispõem.


---

## 🔨 Funcionalidades:
- Cadastro de aluno/instrutor
- Cadastro de aparelhos
- Cadastro de grupo
- Cadastro de exercício para grupo
- Listagem dos alunos/ instrutores

---
## 🛠️ Ferramentas:
- Java 17
- Visual Studio
- Spring Boot
- Spring Web
- JPA
- Maven
- MVC
- Bootstrap
- html
- css
- Postgresql
- Lombok
